# Introduction to Nota

Nota is a decentralized, verifiable accounting platform built natively on **Arc Network**. It allows merchants and individuals to issue cryptographically signed receipts, manage cashflow, and verify transactions with instant settlement in USDC.

## Key Features

- **Verifiable Receipts**: Receipts anchored on Arc blockchain via data-hash.
- **USDC-First Settlement**: Direct payments with zero volatility risk.
- **Multi-Currency UI**: Automatic conversion for IDR, MYR, SGD, and USDC.
- **Analytics & Cashflow**: Two-sided insights for merchants and payers.
